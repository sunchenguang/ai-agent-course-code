# A 股板块发现技能

当用户**未给出具体股票**，而是询问「最近有哪些值得关注的方向/板块/领域/热点」时使用本技能。

## 前置条件

- `MCP_SECTOR_ENABLED=true`（依赖 stock-sdk-mcp 板块 API）
- 服务端已在流式入口**预执行**板块发现时，主 Agent 直接沿用返回的 tickers，无需重复调用

## 适用场景

- 「A 股最近有哪些值得关注的方向？」
- 「当前热点板块有哪些，各推荐 2 只股票」
- 「帮我发现值得关注的行业和对应标的」

## 执行步骤

### 1. 确认发现模式

若会话已注入板块发现结果（research targets 已含 tickers），**跳过**重复发现，直接进入调研。

若预发现失败或未执行，**必须**调用 `discover_hot_sectors` 工具。

### 2. 向用户简要说明发现结果

用 3–5 句话概括：

- 选中的 Top 3 板块名称与当日涨跌幅
- 各板块选取的成分股（代码 + 名称）
- 声明：按**当日涨跌幅**排序，仅为热点快照，非投资建议

### 3. 进入标准投研流程

按 `stock-research` 技能继续：

1. `write_todos` 规划
2. 并行委派 `market-researcher`（每股一个 task，theme 用板块名拼接）
3. 委派 `quant-analyst` → `generate_streaming_report`

## 约束

- **禁止**在未调用工具/未有预发现结果时，凭 LLM 记忆编造板块或股票
- 发现结果仍须走 `compute_stock_ranking`，分数不得手写
- 报告须增加「领域概览」小节，列出 3 个板块及选取理由（涨跌幅、领涨股）
- 全文中文，末尾免责声明

## 不在本技能范围

- 基金推荐（第二期）
- 美股行业发现（第二期）
