# 投研报告撰写技能

将 findings 与 ranking.json 综合为最终交付物时使用本技能。

> **注意**：本技能是主 Agent 的写作指南，不是子 Agent。请主 Agent 亲自用 `write_file` 撰写报告。

## 报告结构

1. **标题** — `# [主题]：股票投研简报`
2. **执行摘要** — 3–5 条核心要点（Top 推荐 + 主要风险）
3. **市场概览** — 主题背景与当前重要性
4. **推荐排序** — 表格或列表，数据必须与 `ranking.json` 一致
5. **个股分析** — 按 ranking 顺序，每只：基本面、动量、情绪、风险
6. **结论** — 直接回答用户问题
7. **风险提示与免责声明** — 数据局限、不构成投资建议
8. **参考资料** — 编号列表，格式 `[标题](URL)`

## 写作规范

- **全文使用中文**（股票代码等专有名词可保留英文）
- 第三人称专业表述
- 所有分数、PE、涨跌幅必须来自 ranking.json 或 market_data 文件
- 关键论断 inline 引用新闻来源

## 文件命名

- 终稿：`reports/report_[主题slug].md`
- 使用 **generate_streaming_report** 工具生成，支持页面流式展示
